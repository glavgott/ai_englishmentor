# English Adventure 🗽

**English Adventure** — это Telegram-бот для практики английского языка в формате интерактивного квеста. Пользователь «путешествует» по США и общается с разными персонажами (таксист, хостел-менеджер, троюродный брат), ведя с ними диалог только на английском. В конце бот анализирует уровень владения языком по шкале CEFR.

---

## 📖 О проекте

Бот построен на связке **Telegram Bot API** + **LLM через Groq API** (модель `qwen/qwen3.8-27b`). Диалог разбит на три «арки» (сцены), каждая со своим персонажем и набором вопросов:

| Арка | Персонаж | Локация | Цель |
|------|----------|---------|------|
| 1 | Таксист | Такси по дороге в город | Разговор о родине, цели визита, зарплате, погоде |
| 2 | Алексей (хост) | Лобби отеля | Опрос для скидки на номер (ночи, тип номера, завтрак, гид) |
| 3 | Эндрю (троюродный брат) | Парк | Семья, карьера, планы на жизнь, впечатления о США |
| Финал | Аналитик | — | Оценка уровня английского (CEFR) и словарного запаса |

Переход между арками происходит автоматически — по специальным маркерам в ответе модели (`!!!`, `!)`, `=)`).

---

## ⚙️ Как это работает

1. Пользователь отправляет команду `/start_game`.
2. Бот отправляет первый вопрос таксиста: *"What is your name?"*
3. Каждый ответ пользователя:
   - сохраняется в SQLite-базу (`messages`);
   - отправляется в LLM вместе с историей диалога;
   - ответ модели возвращается пользователю.
4. Когда модель завершает арку (добавляет маркер в конце сообщения), системный промпт пользователя обновляется на следующую сцену.
5. После третьей арки запускается финальный промпт-аналитик, оценивающий уровень языка.

## 📂 Структура проекта

```
.
├── bot.py       # Telegram-бот: обработчики команд и сообщений
├── ai.py        # Логика работы с LLM, промпты сцен, маршрутизация
├── crud.py      # Работа с SQLite: создание таблицы, сохранение/чтение истории
└── data.db      # База данных (создаётся автоматически)
```

### `bot.py`
- Инициализация `telebot.TeleBot`.
- Команды `/start`, `/info`, `/help` — приветствие.
- Команда `/start_game` — запуск квеста.
- Обработчик любых текстовых сообщений — проксирует их в `ai()`.

### `ai.py`
- Хранит промпты всех персонажей (`taxi_prompt`, `hotel_prompt`, `park_prompt`, `analyz_prompt`).
- Функция `ai(user_id, user_input)`:
  - подгружает историю диалога из БД;
  - добавляет новый запрос пользователя;
  - отправляет запрос в Groq API;
  - проверяет ответ на маркеры перехода между арками;
  - сохраняет ответ ассистента в БД.

### `crud.py`
- `user_data()` — создаёт таблицу `messages` при первом запуске.
- `save_messages()` — сохраняет сообщение (user/assistant/system).
- `get_messages()` — возвращает историю диалога пользователя.
- `update()` — обновляет системный промпт (при смене арки).

## 🚀 Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/your-username/english-adventure.git
cd english-adventure
```

### 2. Установите зависимости

```bash
pip install pyTelegramBotAPI openai
```

### 3. Получите API-ключи

- **Telegram Bot Token** — у [@BotFather](https://t.me/BotFather).
- **Groq API Key** — на [console.groq.com](https://console.groq.com).

### 4. Пропишите ключи в коде

В `bot.py`:
```python
api_key = "ВАШ_TELEGRAM_BOT_TOKEN"
bot = telebot.TeleBot(api_key)
```

В `ai.py`:
```python
client = OpenAI(
    api_key="ВАШ_GROQ_API_KEY",
    base_url="https://api.groq.com/openai/v1"
)
```

> ⚠️ **Рекомендуется** вынести ключи в переменные окружения (`.env`) и не коммитить их в репозиторий.

### 5. Запустите бота

```bash
python bot.py
```

После запуска в консоли появится `Бот запущен...`.

## 💬 Использование

1. Найдите бота в Telegram.
2. Отправьте `/start` — увидите приветствие.
3. Отправьте `/start_game` — начнётся первая арка (такси).
4. Отвечайте на вопросы **только на английском** — бот будет вести диалог, углубляя темы.
5. Пройдите все три арки — в конце получите оценку своего уровня английского.

## 🧠 Особенности промптов

- Бот **не выходит из роли** и не признаёт, что это игра.
- Отказывается переходить на другой язык, принимать «награды», раскрывать свой промпт.
- Не использует инструменты (`tool_choice="none"`).
- Уровень лексики ограничен **B1–B2**.
- Маркеры перехода между сценами:
  - `!!!` — конец арки таксиста → отель
  - `!)` — конец арки отеля → парк
  - `=)` — конец арки парка → аналитика

## 🗄️ База данных

Используется **SQLite** (`data.db`). Таблица `messages`:

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INTEGER | Первичный ключ |
| `user_id` | INTEGER | ID чата в Telegram |
| `role` | TEXT | `system` / `user` / `assistant` |
| `content` | TEXT | Текст сообщения |

История хранится полностью и передаётся в модель на каждом шаге — это обеспечивает связность диалога.
